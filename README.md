# OracleWarehouseERP

Object-relational warehouse and production management system for a dairy, implemented in Oracle PL/SQL. The project models suppliers, contractors, recipes, production batches, deliveries, inventory fields, product shelf life, and warehouse operations directly in Oracle database objects.
Main file - baza.sql
Packages - kierownik_pkg.sql, pracownik_ds_dostaw_pkg.sql, baza/magazynier_pkg.sql, 
Project includes sample database use scenarios in testy folder

Lodz University of Technology project, 2025.
